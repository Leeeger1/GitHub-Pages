# 自己做皮肤

牛马工作室的皮肤可以自己做：界面颜色、办公室的墙和地板、窗外风景、飘落效果、墙纸，大家要不要戴猫耳，都能改。做法有两种，做出来的东西是一样的：

- **点点鼠标**：软件里点皮肤栏最后的「**＋ 做皮肤**」，改一个颜色，后面的办公室马上跟着变，满意了点「保存」。
- **写皮肤文件**：复制 [模板](skins/template.json)，用记事本改颜色，放进皮肤文件夹。

![做皮肤编辑器](skin-editor.png)

## 用编辑器做

1. 点页面右上角皮肤栏最后的「**＋ 做皮肤**」（桌面版也可以用菜单「皮肤 → 做皮肤 / 改皮肤…」）。
2. 起个名字，选「从哪套改起」（樱花、夜班、赛博霓虹、猫耳咖啡、像素复古）。
3. 最快的办法：在「**一键配色**」里选一个喜欢的颜色，点「用这个颜色配一整套」，界面和办公室的颜色都会自动配好。不知道选什么就点「🎲 随机一套」，不喜欢再点。想要深色的，先勾上「深色皮肤」。
4. 再按喜好细调：
   - 「界面颜色」：页面背景、面板、文字、强调色……
   - 「办公室」：窗外风景（樱花、城市夜景、赛博城市、花园、大海、只有天空、自己的图片）、飘落效果（花瓣、雪花、星光、泡泡）、墙上花纹（猫爪、圆点、竖条、霓虹格子），还有猫耳、养猫、台灯、霓虹灯几个开关。墙、地板、天空、桌子、植物的颜色都能单独改（「更多颜色」里还有十几项）。
   - 「图片」：选一张墙纸，或者一张窗外的风景图（png、jpg、gif、webp，4MB 以内）。
5. 点「**保存**」。皮肤栏里就多了这一套，点一下就能换上。

要改已经做好的皮肤：先在皮肤栏里换上它，这时按钮会变成「✎ 改皮肤」，点开就是它。改完可以「保存修改」，也可以「另存为新皮肤」。不想要了点「删除」。

## 写皮肤文件

### 放在哪

| 系统 | 皮肤文件夹 |
|---|---|
| Windows | `C:\Users\你的用户名\.niuma\skins\` |
| macOS | `/Users/你的用户名/.niuma/skins/` |
| Linux | `~/.niuma/skins/` |

不用自己找：编辑器底部有「打开文件夹」，桌面版菜单里有「皮肤 → 打开皮肤文件夹」。

两种放法都行：

```
.niuma/skins/
├── 海边.json              ← 一个文件就是一套皮肤，文件名随便起
├── 墙纸.png               ← 海边.json 里写 "wall": "墙纸.png" 就能用
└── 雪夜/                  ← 或者一个文件夹一套（编辑器存的就是这种）
    ├── skin.json
    └── window.jpg
```

放进去以后回到牛马工作室的窗口，皮肤栏里就会多出来。**改了文件也一样，切回窗口就会重新读**，不用重启。

### 从模板开始

[`docs/skins/template.json`](skins/template.json) 把每一项都写出来了，每行都有中文说明，本身就是一套能用的皮肤（海边度假）。复制一份、改名、改颜色就行。

只想改几个颜色的话，写你想改的就够了，其余照 `base` 那套来。比如 [`minimal.json`](skins/minimal.json)：

```jsonc
{
  "name": "薄荷",
  "base": "sakura",
  "colors": { "accent": "#1faa84" },
  "room": { "window": "sky", "particles": "none" }
}
```

另一个例子：[`snow-night.json`](skins/snow-night.json)（雪夜：在夜班的基础上下雪、开台灯）。

### 写法规则

- 就是普通的 JSON，另外允许 `//` 注释和末尾多一个逗号。
- 颜色可以写 `"#1e9bd7"`、`"#19d"`、`"rgb(30,155,215)"`、`"rgba(0,0,0,.2)"`、`"white"`。
- 写错的项会被跳过，不影响别的项；在编辑器底部能看到哪个文件哪里写错了。
- 图片写文件名，图片要放在皮肤文件旁边（或者它所在的文件夹里），支持 png、jpg、gif、webp，每张不超过 4MB。

### 全部设置

**基本**

| 项 | 意思 | 可以写 |
|---|---|---|
| `name` | 皮肤名字，显示在皮肤栏 | 24 个字以内 |
| `base` | 从哪套内置皮肤改起，没写的项都照它来 | `sakura` 樱花、`night` 夜班、`neon` 赛博霓虹、`neko` 猫耳咖啡、`pixel` 像素复古 |
| `dark` | 深色皮肤 | `true` / `false` |
| `author` | 作者 | 随便写 |
| `font` | 标题「牛马工作室」的字体 | 电脑上装了的字体名 |

**界面颜色 `colors`**

| 项 | 意思 |
|---|---|
| `bg` | 页面背景 |
| `panel` | 面板（聊天、任务板、项目组卡片） |
| `panel2` | 面板里的浅色块、头像底色 |
| `ink` / `muted` | 文字 / 次要文字 |
| `line` / `edge` | 分隔线 / 面板边框 |
| `drop` | 阴影（一般写强调色的淡色，比如 `rgba(30,155,215,.16)`） |
| `accent` / `onAccent` | 强调色（标题、按钮、选中） / 强调色按钮上的字 |
| `ok` / `warn` / `bad` | 成功 / 提醒 / 出错 |

**办公室 `room`**（二次元画面；`base` 是 `pixel` 时不起作用）

| 项 | 意思 | 可以写 |
|---|---|---|
| `window` | 窗外风景 | `sakura` 樱花、`city` 城市夜景、`cyber` 赛博城市、`garden` 花园、`sea` 大海、`sky` 只有天空、`image` 用 `images.window` 的图片 |
| `particles` | 飘落效果 | `petals` 花瓣、`snow` 雪花、`stars` 星光、`bubbles` 泡泡、`none` |
| `wallPattern` | 墙上花纹 | `paws` 猫爪、`dots` 圆点、`stripes` 竖条、`grid` 霓虹格子、`none` |
| `catEars` / `cat` / `lamps` / `neon` | 大家戴猫耳 / 养猫 / 工位台灯 / 霓虹灯 | `true` / `false` |
| `wall` `floor` | 墙、地板（上下渐变） | 两个颜色 `["#…", "#…"]` |
| `sky` | 窗外天空（上、中、下） | 三个颜色 |
| `plant` | 盆栽叶子（亮、暗） | 两个颜色 |
| `wainscot` `trim` `floorLine` | 墙裙、墙裙线、地板缝 | 颜色 |
| `desk` `deskTop` `deskEdge` | 工位桌子、桌面、桌子描边 | 颜色 |
| `monitor` `monitorEdge` | 显示器、显示器边框 | 颜色 |
| `table` `tableEdge` `rug` | 会议桌、会议桌描边、地毯 | 颜色 |
| `frame` `frameEdge` | 窗框和钟、窗框描边 | 颜色 |
| `boss` `bossEdge` | 傻妞的桌子、描边 | 颜色 |
| `ink` `pot` | 钟的指针、花盆 | 颜色 |

**图片 `images`**

| 项 | 意思 |
|---|---|
| `wall` | 墙纸，铺满墙的上半截（贴了墙纸就不画墙上花纹） |
| `window` | 窗外的风景图（`room.window` 要写 `"image"`） |

## 分享皮肤

- 编辑器里点「**导出文件**」，得到一个 `.json` 文件（图片也打包在里面），发给朋友。
- 朋友在「做皮肤」里点「**导入文件**」，看着满意点「保存」；或者直接把文件放进皮肤文件夹。
- 别人的皮肤文件里只会用到颜色、图片和上面这些选项，别的东西会被忽略，放心用。

## 常见问题

**改了文件没变化？** 切回牛马工作室的窗口就会重新读。还不行就看编辑器底部有没有「有 N 个皮肤文件读的时候出了问题」，点开能看到哪一行写错了。

**像素复古能改吗？** 能改界面颜色。像素风的办公室是一整张像素画，改不了颜色；想改办公室，`base` 换成二次元的几套。

**用编辑器改手写的皮肤文件会怎样？** 会按编辑器里的样子重新写一遍这个文件，文件里原来的注释会没掉，颜色都在。

**网页演示里做的皮肤存在哪？** 存在这个浏览器里，换浏览器就没了。想留着就「导出文件」。
